# Project Rules & Customizations

This file outlines workspace guidelines and data provider preferences.

---

## 1. Market Data Providers

* **Finnhub**: Primary provider for market news, company metadata profiles, and supplementary market quotes.
* **ExchangeRate-API**: Used to compute currency conversions based on user preference profiles, converting native currency figures (e.g. INR) into preferred display currencies (e.g. USD).
* **Native Currency Default**: Always default to displaying native market currencies (e.g. ₹ for NSE stocks, $ for NYSE/NASDAQ stocks) when presenting financials and valuations.
